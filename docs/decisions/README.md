# 重要决策

本目录使用 Architecture Decision Record（ADR）保存已采纳、会影响多个模块或版本的重要决策。编号使用四位递增序号，不复用也不重排。

每份 ADR 必须包含：状态、日期、背景、决策、替代方案和影响。决策被替代时，保留原文件并在状态中标明被替代关系。
