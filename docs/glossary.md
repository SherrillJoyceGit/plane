# 术语表

本表定义文档、需求和实现讨论中的规范用语。代码、API 和数据库标识符保持原文；需要歧义解释时链接到相应架构或决策文档。

| 中文名称 | 英文/API 名称               | 定义                                           | 禁用或需避免的别名           | 来源                            |
| -------- | --------------------------- | ---------------------------------------------- | ---------------------------- | ------------------------------- |
| 工作空间 | Workspace (`workspace`)     | 管理成员、项目和工作项的顶层协作范围。         | 团队、组织（未说明上下文时） | `apps/api`、`apps/web`          |
| 项目     | Project (`project`)         | 工作空间内用于组织工作项和相关配置的业务实体。 | 工程、仓库                   | `apps/api`、`apps/web`          |
| 工作项   | Issue / Work item (`issue`) | 可被计划、分配和追踪的通用工作单元。           | Bug、问题（仅缺陷场景可用）  | `apps/api`、`apps/web`          |
| 模块     | Module (`module`)           | 用于组织相关工作项的一组业务对象。             | 功能、版本包                 | `apps/api`、`apps/web`          |
| 版本     | Version                     | 一组按 `tc-vX.Y.Z` 管理的变更和发布范围。      | 迭代（除非明确指时间盒）     | [版本与分支管理](versioning.md) |
| 路线图   | Roadmap                     | 尚未完成的功能列表及其版本状态。               | 待办清单                     | [路线图](roadmap.md)            |
| 功能归档 | Feature archive             | 已完成且可追溯的版本功能记录。                 | 历史功能列表                 | [功能归档](features-archive.md) |
