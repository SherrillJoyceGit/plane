# 术语约定

这里只记录 TC Plane 与上游 Plane 不同或容易混淆的用语。代码标识符、路径和 API 字段保持原文。

| 文档用语 | 代码/API                    | 约定                                                                                        |
| -------- | --------------------------- | ------------------------------------------------------------------------------------------- |
| 工作项   | Issue / Work item (`issue`) | 中文界面和定制文档统一使用“工作项”；仅在明确表示缺陷类型时使用“Bug”。                       |
| 产品版本 | Module (`module`)           | 上游 Plane 的 Module 在 TC Plane 中显示为“版本”；可能与发布版本混淆时，文档写作“产品版本”。 |
| 发布版本 | Release version             | 代码交付范围，使用 `X.Y.Z`、版本分支 `version/tc-vX.Y.Z` 和标签 `tc-plane-vX.Y.Z` 表示。    |
| 功能编号 | Feature ID（例如 `F-0001`） | 路线图与功能归档之间的稳定引用；编号一经使用便不复用。                                      |
