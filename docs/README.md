## 维护规则

- 在同一提交中同时更新代码和受影响的文档；不在路线图中记录已经完成的功能。
- 路线图中的功能编号从 `F-0001` 起连续分配，不复用已归档或取消的编号。
- 功能完成后，保留编号并移入功能归档，附上完成日期和可追溯的交付链接。
- 重要且可选方案明确的决策使用 ADR 记录；目录索引和决策文件必须同步更新。
- 使用相对链接，链接目标移动时在同一变更中修复引用。

日常开发、检查和测试入口参见仓库根目录的 [AGENTS.md](../AGENTS.md)、[README.md](../README.md) 以及各应用的 README 和测试文档。
